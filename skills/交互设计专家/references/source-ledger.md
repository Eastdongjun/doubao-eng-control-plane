# Source Ledger

This skill is an original synthesis. External materials are used to verify principles, identify useful workflow structures, and provide further reading. No third-party skill text, screenshots, brand assets, or proprietary examples are redistributed.

## Open-source workflow references

- [pbakaus/impeccable](https://github.com/pbakaus/impeccable) — interaction and interface critique prompts; Apache-2.0 at review time.
- [wshobson/agents](https://github.com/wshobson/agents) — modular agent-skill organization, progressive disclosure, and cross-harness packaging; MIT at review time.
- [garrytan/gstack](https://github.com/garrytan/gstack) — evidence-backed design review, usability checks, and executable review loops; MIT at review time.
- [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) — broad UI/UX reference routing; MIT at review time.

The skill adopts no repository as an authority. It keeps useful structures only when they survive first-principles review, accessibility requirements, system governance, and realistic implementation.

## Research-only references

Public gists, articles, pattern libraries, and product-flow galleries may be used as discovery leads. Materials without a clear reusable license are reference-only: extract general mechanisms, cite the source, and do not copy wording, code, screenshots, or distinctive expressions.

## Review rules

Before importing anything:

1. Verify the exact upstream source and current license.
2. Separate universal principle, platform convention, project constraint, and author preference.
3. Re-express useful mechanisms in this skill’s own framework.
4. Reject rules that conflict with evidence, accessibility, user agency, or approved system governance.
5. Record time-sensitive platform guidance with a review date.
