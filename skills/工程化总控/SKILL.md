# 工程化全流程总控（编排层）

把软件项目组织为 12 个可验证阶段。收到项目任务后：**建清单 → 定位阶段 → 路由技能 → 执行任务 → 验证退出 → 推进下一阶段**。所有具体方法由 GitHub 开源专项技能承担，本技能只做编排与任务跟踪。

## 核心机制：任务清单 + 自动执行

1. **建立任务清单（TodoWrite）**：项目启动即用 TodoWrite 建立 12 阶段任务清单，每阶段一个任务项，格式：`[阶段N] <阶段名>：<本阶段关键产物>`。每完成一个阶段，勾选该项并新建下一阶段任务。
2. **拆解任务（编写计划）**：进入新阶段时，用 编写计划 把该阶段需求拆成可执行微任务（含验收步骤）。
3. **分批执行（执行计划）**：按批次执行任务（默认每批 3 个），每批结束报告结果与验证输出，确认后继续下一批——直到该阶段全部任务完成。
4. **检查退出条件**：每阶段结束后逐项核对退出条件（见路由表），未达成则回到该阶段补齐，不进入下一阶段。
5. **维护追踪链**：每阶段产物同步到 需求追踪矩阵 的追踪矩阵，保证需求→设计→代码→测试→版本→指标可追溯。

## 阶段流转规则

- **不跳阶段**：退出条件未达成不进入下一阶段；用户催促时说明缺口与风险。
- **多项目并发**：每个项目独立保存状态（项目名 + 当前阶段 + 已勾选任务），用 TodoWrite 分项目跟踪。
- **阶段回退**：新需求影响已完成阶段时，先用 变更影响分析 做变更影响分析，更新受影响产物与追踪矩阵，再继续。
- **八项贯穿能力**：每阶段产出时检查——进度/风险（任务分解）、需求编号/基线（需求架构）、版本管理（CI-CD流水线）、质量门禁（质量门禁）、权限/漏洞（安全威胁评审）、数据标准（数据建模 + 合规与隐私）、文档随版本（文档与决策记录）、可回滚（运维助手）。

## 自动触发建议

- 模糊需求 → 进入阶段 1（想法打磨）或阶段 2（需求架构），不直接写代码。
- 具体功能 → 先查追踪链有无需求/设计依据；没有先补再开发。
- "上线/发布" → 先加载 上线发布 检查上线准备，再进入发布。
- 线上故障 → 按 事故管理 流程处理，回填事故复盘。
- 变更需求 → 先 变更影响分析 评估影响，再决定回退到哪个阶段。

## 技能协同机制（189 技能全量注册）

本机技能库已全量注册到 `.governance/capability_registry.json`（由仓库 `governance-demo/skill_registry_builder.py` 自动重建）。编排路由时遵循以下机制，保证技能不打架、能串联：

### 1. 不确定用哪个技能 → 查注册中心
用 Bash 运行 `python3 governance-demo/skill_registry_builder.py query`，或读 `.governance/capability_registry.json`，按 description / 阶段 / 冲突分组定位准确技能；不要凭印象猜技能名。

### 2. 冲突消解（同组技能按场景选，避免叠加触发）
- **代码审查族**：本地改动→代码审查；PR/diff→pr审查专家；方案多视角→具名角色对抗审查；接口契约→api设计审查；依赖→依赖审计
- **测试族**：网页端→网页测试；端到端浏览器→Playwright专业；性能压测→性能测试；TDD 写码→测试驱动开发；测试资产管理→测试用例追踪
- **安全族**：AI 应用→AI安全；云设施→云安全；主动攻击模拟→渗透测试/红队；持续监测→威胁检测；Web 应用→owasp安全
- **架构族**：整体方案→高级架构师；评审已有→架构评审引导；选型取舍→权衡分析；技术盘点→技术栈评估
- **数据库族**：结构设计→数据库设计；物理表→数据库表结构设计；调优→数据库优化；质量→数据质量审计

### 3. 技能契约（保证阶段间可串联）
- 每个专项技能：**输入** = 项目上下文（项目路径 + 需求 + 追踪矩阵）；**输出** = 标准 Markdown 产物写入项目目录并命名 `阶段N_<产物名>.md` + 回填追踪矩阵。
- **交接**：上一阶段产物路径作为下一阶段技能输入，避免重复调研、保证数据口径一致。
- **留痕**：每个技能执行后追加一行到 `.governance/trace.jsonl`（task_trace.py），记录：阶段、技能、产物路径、耗时、结果。

### 4. 新增技能自动入编
新增技能装入 `.user_skills` 后运行 `python3 governance-demo/skill_registry_builder.py build`，自动完成注册、冲突分组、阶段映射，无需手工维护注册表。
