# Layout Intelligence, Freshness, and Anti-Convergence

Use this module when a project has no binding visual specification, when a redesign feels generic or dated, when a user asks for contemporary or exceptional composition, or when recent outputs repeat the same page silhouette. The goal is not novelty for its own sake. It is to derive a layout from the content, task, brand, and current visual field while preventing the agent's habitual template from becoming the design.

## 1. Resolve aesthetic authority

Before choosing final layout, typography, palette, imagery, or material, label the authority state:

| State | Meaning | Required action |
|---|---|---|
| `binding-system` | An approved design system, brand system, or component library governs the work | Inherit it. External references may help solve a local problem but cannot silently replace the system. |
| `user-directed` | The user supplied approved references, anti-references, or a clear direction | Deconstruct the evidence into mechanisms, verify conflicts, and preserve the user's intent. |
| `research-derived` | A current, project-specific corpus supports a direction | Record sources, date, synthesis, and the decision that selected it. |
| `unresolved` | No approved system, useful references, or researched direction exists | Automatically begin proportional research before high-fidelity visual decisions. |

When authority is `unresolved`, information architecture, content hierarchy, flows, states, and grayscale structural work may continue. Final palette, display type, decorative material, and presentation layout may not be presented as resolved.

If live research is available, use it. If it is unavailable, use the built-in grammar and source registry only as a hypothesis, label currentness as unverified, and request visual calibration before claiming `Authored` or `Inevitable` finish.

## 2. Run proportional live research

Research depth follows visual risk rather than a universal ceremony.

### Conformance or maintenance

- Start from the approved system and shipped product.
- Research externally only for a defined gap, usability question, or authorized evolution.
- Do not import a current visual fashion into a stable product merely to make it feel new.

### Complete product or application without a visual authority

Use a bounded field sufficient to avoid category blindness:

- Direct category products and competitors with real, shipped flows
- One or more category leaders outside the immediate competitor set
- Adjacent editorial, service, or tool experiences with a transferable information problem
- Explicit counter-references showing the dominant template or trust failure
- Mobile evidence, dense states, and ordinary utility screens, not homepages alone

Six to twelve consequential examples across at least three lanes is a useful starting envelope, not a quota. Stop when new examples no longer change the hierarchy, structural options, or known convergence risks.

### Brand, editorial, cultural, launch, portfolio, or flagship work

Expand into primary artifacts, current production, graphic/editorial design, typography, architecture, exhibition, film, fashion, art, motion, and counter-references as relevant. Use the fuller research envelope in [aesthetic-discovery-research.md](aesthetic-discovery-research.md).

Do not let research consume the project without changing a decision. Every retained source must explain a mechanism, boundary, or rejected default.

## 3. Maintain a living reference field

Static screenshots are fallback evidence, not permanent authority. Build the project corpus from complementary sources:

| Evidence lane | Useful starting sources | What it can prove | Bias to control |
|---|---|---|---|
| Real product behavior | Official live products, supplied analytics or recordings, Mobbin | tasks, states, content density, mobile behavior, operational reality | popular products can normalize category convention |
| Current web composition | SiteInspire, Codrops Creative Hub and case studies, Lapa Ninja | page silhouettes, typography, spatial rhythm, motion, implementation ideas | showcase sites overrepresent marketing and spectacle |
| Identity and editorial systems | BP&O, Fonts In Use, current publications and studios | type-image relationships, identity logic, editorial rhythm, print-to-screen translation | published work may omit product constraints |
| Research and visual culture | Are.na channels, museums, archives, libraries, exhibitions, practitioner documentation | adjacency, lineage, material, cultural context, counterintuitive connections | curation is a lead, not verified fact |
| Platform and system behavior | Official platform HIGs and maintained design systems | semantics, accessibility, native behavior, supported material | platform language is not automatically the brand language |
| Counter-reference | dominant category sites, template marketplaces, historical snapshots, recent agent outputs | saturation, clichés, repeated silhouettes, false claims of modernity | critique still needs project context |

For every consequential source record:

```text
source / creator / URL
published or shipped date / checked date
lane / category / platform / viewport
direct observation / inference
layout signature
transferable mechanism
do-not-copy boundary
mobile behavior
accessibility, performance, rights, and implementation risk
revisit or expiry trigger
```

Refresh project-specific examples at the start of the task whenever the brief depends on “current,” “modern,” “fresh,” or a recent category baseline. Check that registry links remain available at least quarterly. Historical sources do not expire in the same way, but their interpretation and reproduction status still require verification.

Do not rely on one gallery. Follow showcased work to its original site, studio, product, case study, or implementation source whenever the observation affects a decision.

## 4. Read layout as a grammar

Analyze composition through independent axes before naming a style:

- **Canvas:** centered frame, edge-to-edge field, rail, layered plane, paged sequence, or continuous surface
- **Grid:** column, modular, baseline, nested, free-placement, data-aligned, or content-derived structure
- **Mass:** dominant block, distributed field, tiny anchor, central specimen, asymmetric counterweight, or repeated index
- **Sequence:** stacked chapters, continuous narrative, comparison, catalog, spatial travel, dashboard, or task flow
- **Edge behavior:** framed, full bleed, clipped, peeking, sticky, off-canvas, or deliberately quiet
- **Density curve:** constant, alternating, cumulative, compressed, release-and-peak, or task-dependent
- **Type-image relationship:** captioned object, image-led field, typographic mass, annotated specimen, overlay, or parallel narrative
- **Navigation:** global bar, rail, index, in-flow anchors, contextual controls, or progressive disclosure
- **Section connection:** isolated cards, shared surface, overlapping transition, rule-based chapters, persistent object, or continuous background
- **Responsive transformation:** resize, reflow, reorder, reframe, collapse, change interaction, or change representation

The following are analytical families, not templates to select mechanically:

| Family | Structural principle | Strong fit | Failure mode |
|---|---|---|---|
| Continuous editorial field | Chapters share one visual world and rhythm instead of becoming isolated card stacks | media, culture, reports, narrative products | weak orientation or exhausting density |
| Index or registry | Repetition, metadata, sorting, and comparison become the composition | archives, catalogs, directories, research | administrative coldness or poor focal hierarchy |
| Rail or spine | A persistent line, column, or navigation anchor controls reading and state | long-form, workflows, timelines, reference tools | cramped mobile translation or overdominant chrome |
| Anchored asymmetry | Unequal masses are balanced through distance, scale, and alignment | editorial, brand, portfolio, product storytelling | arbitrary imbalance disguised as expression |
| Typographic poster | Language is both information and compositional mass | campaigns, launches, cultural work | headline spectacle with weak reading and utility states |
| Dense workbench | Information follows task, comparison, and action geometry | finance, operations, data tools, professional software | fake complexity, telemetry decoration, or unreadable compression |
| Full-bleed medium with quiet core | Immersive image or material frames a conventional interaction core | media, fashion, hospitality, entertainment | media overwhelms navigation, forms, or performance |
| Spatial narrative | Persistent objects and controlled transitions make sequence feel spatial | demonstrations, stories, exhibitions, learning | scroll control, disorientation, inaccessible motion |
| Content-shaped modules | Module scale follows information priority and relationship | mixed-content products, dashboards, editorial packages | compulsory bento mosaic with equal-looking cards |

Do not choose a family because it is newer. Combine or mutate principles only when the content model and user task explain the result. A familiar structure is acceptable when it is the clearest choice; it becomes a problem when it appears by habit and carries no project-specific rationale.

## 5. Produce competing silhouette proofs

Before final color and surface treatment, prove the structure in grayscale.

Use the same representative content, assets, functional requirement, and viewports. Keep placeholder imagery neutral enough that image style cannot rescue weak composition.

- A low-risk unresolved layout normally needs two materially different silhouettes.
- A flagship or identity-defining layout normally needs three.
- A binding conformance task may use one compliant baseline when there is no unresolved structural decision.

Directions must differ in at least three consequential axes such as canvas, mass distribution, grid, sequence, density curve, navigation, type-image relationship, or responsive transformation. Colorways, radius changes, swapped images, and minor card rearrangements do not count.

Each direction must show:

1. A representative desktop or large-screen silhouette
2. A representative mobile silhouette
3. The signature moment
4. An ordinary utility, dense, form, or recovery state
5. First-read path and primary action
6. Content stress with realistic lengths
7. The structural reason this direction belongs to the project

Compare at thumbnail, reading distance, and close inspection. Reject a direction whose hierarchy works only after color, animation, or decorative material is added.

## 6. Record and challenge the layout fingerprint

Create a compact fingerprint before approving a direction:

```text
canvas / global navigation / hero or entry silhouette
section sequence / primary information unit / density curve
edge use / type-image relation / signature transition
mobile order / mobile navigation / mobile representation
```

Example notation may be short, but the meanings must be explicit:

```text
C:centered | N:top | E:split | U:cards | D:even | S:bands | M:stack
```

Compare the fingerprint against:

- dominant direct-competitor structures
- explicit counter-references
- template-marketplace category defaults
- recent outputs from the same agent or project, when available
- the other candidate directions in the current task

Treat compound repetition as the warning. Individual patterns are not banned. Examples of common compound signatures include:

- centered top navigation + left-copy/right-media hero + floating proof card + three metrics
- centered headline + pill actions + logo strip + equal card grid + testimonial band
- alternating light/dark full-width sections + repeated rounded panels + identical reveal motion
- desktop sections mechanically reduced to one vertical mobile stack with unchanged priority
- dark field + fluorescent accent + monospace labels + grid overlay + fake telemetry

If a candidate repeats three or more dominant structural choices in the same sequence and cannot explain them from content, task, brand, or platform evidence, it fails the convergence check. Regenerate from a different canvas, sequence, information unit, or density model before changing decoration.

When a conventional pattern is necessary, state why, keep the conventional interaction contract, and place authorship in a bounded project-specific relationship rather than novelty garnish.

## 7. Recompose for mobile

Mobile is a new composition under tighter attention and input constraints, not the desktop page stacked vertically.

For each breakpoint family decide explicitly:

- what becomes first, deferred, summarized, grouped, paged, or removed
- whether navigation changes model instead of only collapsing
- whether a comparison becomes tabs, a table, a sequence, or a focused detail view
- how dense data preserves labels, units, time context, and scan paths
- how image crop, type measure, edge use, and negative space change
- where sticky controls help and where they consume too much viewport
- how hover, spatial motion, and wide-screen relationships receive touch, keyboard, static, and reduced-motion equivalents

A mobile layout may preserve the desktop order when that order is already correct. The requirement is to make the choice deliberately and verify it, not to force difference.

Run first-screen, one-hand reach, text expansion, long CJK/Latin content, landscape, zoom, slow-network, keyboard/focus, and reduced-motion checks as relevant.

## 8. Apply the freshness jury

Freshness is contextual contemporaneity and specificity, not trend density.

Reject or revise when any of these conditions holds:

- “Modern” or “current” is asserted without a live evidence date.
- The page resembles the dominant category template but no business or usability reason is recorded.
- Multiple directions share nearly the same silhouette.
- Palette, imagery, or motion is being used to disguise a generic structure.
- The layout borrows a current gesture with no lineage, role, or half-life discussion.
- Ordinary states collapse into generic components unrelated to the signature direction.
- Mobile is only a compressed desktop stack.
- The result feels novel at full size but loses hierarchy at thumbnail or first read.

Approve only when:

- purpose, content model, and user task explain the structure
- a current category baseline and counter-reference field were inspected when required
- the selected silhouette is distinct for a meaningful reason
- conventional and expressive regions have clear boundaries
- the direction survives grayscale, realistic content, mundane states, mobile, and reduced motion
- the layout can generate further pages without repeating one showpiece composition
- its temporal stance is named: timeless, current, emerging, period-rooted, anti-trend, or intentionally familiar

## 9. Run regression cases

Use diverse prompts to test whether the skill changes its composition instead of decorating one template:

| Case | Required evidence | Convergence to reject |
|---|---|---|
| Futures-industry news and data publication | editorial hierarchy, trust, market data, mobile scanning | SaaS split hero, isolated marketing cards, decorative dashboards |
| Resume or portfolio for a futures-media role | editorial judgment, credible evidence, fast recruiter scanning, print and mobile behavior | startup landing-page hero, floating proof panel, three-metric strip, 2×2 case cards, alternating promo bands |
| Elder-care service | reassurance, service clarity, caregiver and resident needs | generic pastel blobs, oversized empty hero, infantilizing imagery |
| Industrial operations software | dense tasks, error recovery, real states | neon dark cockpit, fake telemetry, cinematic chrome everywhere |
| Children's museum | age range, family navigation, learning and delight | stickers and bouncing shapes as the entire concept |
| Law or compliance service | authority, comprehension, consequences | black-gold luxury, giant serif plus empty space, hidden detail |
| Tang-period mineral-color cultural site | primary artifacts, material research, modern translation | Dunhuang clip art, faux parchment, generic national-style motifs |
| Developer tool | documentation, task flow, code and product evidence | dark mesh, fluorescent green, monospace labels used as identity |
| Fashion or cultural editorial | image rights, type-image rhythm, publishing model | giant display type and full bleed with no content system |
| Existing mature design system | approved sources, tokens, component behavior | unauthorized refresh, parallel token layer, imported trend grammar |

For a regression session, render or outline comparable desktop and mobile silhouettes, record fingerprints, and inspect them as a contact sheet. The set fails if one compound silhouette dominates unrelated cases or if color/style labels are the main source of difference.

## 10. Output contract

For layout-sensitive work, include a **Layout Decision Record**:

1. Authority state and governing evidence
2. Research tier, sources, check date, and stopping reason
3. Category baseline and explicit counter-references
4. Content model, attention order, and responsive priorities
5. Competing grayscale silhouettes using comparable content
6. Fingerprint for every direction and convergence findings
7. Selected grammar, project-specific mutation, and deliberate conventional core
8. Desktop/mobile recomposition rules
9. Thumbnail, grayscale, content, mundane-state, and accessibility evidence
10. Temporal stance, expiry risk, rejected alternatives, owner, and revisit trigger

Do not claim the layout is fresh, authored, or current from prose alone. Show the silhouettes or state that the direction remains visually unproven.
