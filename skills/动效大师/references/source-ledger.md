# Source Ledger

This skill is an original synthesis. External sources are used to compare approaches, identify reusable principles, and direct further research. No third-party source code, prose, clips, sound, images, fonts, brand assets, or distinctive sequences are redistributed.

## Open-source motion and workflow references

- [emilkowalski/skills](https://github.com/emilkowalski/skills) — deciding whether motion should exist, frequency-aware restraint, animation critique, vocabulary, and prototype loops; MIT at review time.
- [wondelai/skills](https://github.com/wondelai/skills) — microinteraction anatomy and product-defining signature moments; MIT at review time.
- [Vincentwei1021/video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft) — shot, camera, and sequence language; Apache-2.0 at review time.
- [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent) — creative coding and p5.js skill patterns; MIT at review time.
- [Google Material Design motion](https://github.com/material-components) — system motion and platform implementation references; verify the exact package license and current guidance.
- [dexhunter/seedance2-skill](https://github.com/dexhunter/seedance2-skill) — camera, reference-role, rhythm, scene, and sound vocabulary for AI-video direction; MIT at review time. Treat model capabilities and output rights as separately governed and time-sensitive.

Useful mechanisms are re-designed inside this skill’s aesthetic, accessibility, governance, and production framework. Upstream content is never copied simply because it is public.

## Selected motion-library registry

These sources support the routing rules in [open-source-motion-library-registry.md](open-source-motion-library-registry.md). No library source code or demo assets are bundled in this skill.

### Default core

- [motiondivision/motion](https://github.com/motiondivision/motion) — Motion for general component, layout, gesture, and scroll-linked motion; MIT at review time.
- [juliangarnier/anime](https://github.com/juliangarnier/anime) — Anime.js for framework-independent DOM, SVG, object, and timeline choreography; MIT at review time.
- [pmndrs/react-spring](https://github.com/pmndrs/react-spring) — React Spring for continuous, interruptible React physics and optional Three.js integration; MIT at review time.
- [formkit/auto-animate](https://github.com/formkit/auto-animate) — AutoAnimate for low-complexity structural layout transitions; MIT at review time.
- [svgdotjs/svg.js](https://github.com/svgdotjs/svg.js) — SVG.js for custom SVG construction and geometry; the root `LICENSE.txt` contained the MIT License at review time even though repository metadata did not declare an SPDX license.

### Auxiliary route

- [3b1b/manim](https://github.com/3b1b/manim) — ManimGL for explanatory mathematics, data, systems, and algorithm video; MIT at review time. Its installation package is `manimgl`; do not confuse it with the separate Manim Community package named `manim`.

### Conditional routes

- [ibelick/motion-primitives](https://github.com/ibelick/motion-primitives) — source/registry motion components for React/Tailwind projects; MIT at review time. Treat adoption as inspected source integration rather than a generic runtime dependency.
- [pqoqubbw/icons](https://github.com/pqoqubbw/icons) — Lucide-compatible animated SVG icon components; MIT at review time. Use only when the approved project icon grammar is compatible.
- [LottieFiles/dotlottie-web](https://github.com/LottieFiles/dotlottie-web) — dotLottie web runtimes for authored animation-asset playback, themes, and state machines; MIT at review time. Rights to individual `.lottie`, JSON, image, font, and audio assets remain separate.
- [rive-app/rive-wasm](https://github.com/rive-app/rive-wasm) — Rive web runtimes for interactive vector state machines; MIT at review time. Rights to individual `.riv` files and embedded assets remain separate.
- [darkroomengineering/lenis](https://github.com/darkroomengineering/lenis) — Lenis for conditional narrative or immersive scroll behavior; MIT at review time.
- [mrdoob/three.js](https://github.com/mrdoob/three.js) and [pmndrs/react-three-fiber](https://github.com/pmndrs/react-three-fiber) — Three.js and React Three Fiber for conditional spatial, shader, material, and 3D work; MIT at review time.
- [motion-canvas/motion-canvas](https://github.com/motion-canvas/motion-canvas) — Motion Canvas for conditional code-driven explanatory vector, data, and educational video; MIT at review time.
- [software-mansion/react-native-reanimated](https://github.com/software-mansion/react-native-reanimated) — React Native Reanimated for conditional native interface and gesture motion; MIT at review time.

Package names, framework compatibility, installation requirements, feature recommendations, releases, and licenses can change. Verify the exact current package and version from its official source before project integration.

## Rights and authorship

Before reuse:

1. Verify the exact repository, commit/tag, and license.
2. Separate code permission from rights to images, fonts, footage, music, voice, logos, and generated output.
3. Extract general mechanisms rather than copying a recognizable treatment.
4. Do not imitate a living motion designer, studio, filmmaker, or brand signature.
5. Record attribution and limitations in the project source ledger.
6. Treat sources with no explicit license as research-only.
